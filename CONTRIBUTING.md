# Contributing to Debuga Community

Obrigado por contribuir com o ecossistema público do Debuga.

## Áreas de Contribuição

São bem-vindas contribuições para:

- documentação;
- traduções;
- instalação;
- troubleshooting;
- templates;
- exemplos;
- monitoramento;
- backup;
- integrações;
- melhorias em componentes públicos.

## Núcleo da Aplicação

O código-fonte principal da aplicação Debuga é mantido separadamente e não
faz parte deste repositório.

Contribuições ao núcleo proprietário seguem outro processo.

## Antes de Enviar

Uma contribuição deve ser:

- focada;
- reproduzível;
- documentada;
- livre de secrets;
- independente de configuração específica de clientes;
- compatível com os modos de deploy publicados.

## Segurança

Nunca envie:

- passwords;
- tokens;
- API keys;
- private keys;
- dumps;
- banco de produção;
- evidências internas;
- dados de clientes;
- código copiado de repositórios privados.

Leia também [SECURITY.md](SECURITY.md).

## Mudanças no Installer

Alterações no Installer recebem revisão adicional.

Não devem:

- introduzir credenciais ocultas;
- enfraquecer autenticação;
- enfraquecer entitlement;
- expor serviços internos sem necessidade;
- remover verificações de integridade;
- alterar plataforma suportada sem homologação.

## Documentação

A documentação deve diferenciar claramente:

- comportamento suportado;
- comportamento experimental;
- recurso planejado;
- item futuro de roadmap.
